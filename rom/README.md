# rom/

Program ROM dumps (64 KB, 27C512 EPROM) for the Elcotel Series 5 board.
Every dump here is listed in the FW ROM tab; the one you pick is remembered.
Add your own the same way (any file name), or open one from that tab.

| File | Firmware | SHA-256 |
|---|---|---|
| `Elcotel_PGM_5.4.4_1999_27C512.BIN` | PCM 05.04.04, the stock Elcotel firmware (1999) | `bd5cacd4351e85b5ca628b5839755089a341397f622f5719744265b76e613233` |
| `ELCTL5-0CC369EA265B.BIN` | PCM 05.09.00, a custom firmware with built-in rates and options (installed with telemetry code 998) | `721a794ca493935038cf7fa548d52035f92cb7fff65c36c5a5caa937ab4528fc` |

Both dumps are courtesy of [payphones.telesfor.org](https://payphones.telesfor.org)
and are included here with their attribution. The Elcotel firmware is
Elcotel's work; these copies are for preservation and study of the hardware.
