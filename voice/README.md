# voice/

Voice ROM dump (128 KB, 27C010 EPROM): the payphone's spoken prompts as
1-bit CVSD. The Voice ROM tab lists and plays every prompt and can open
another dump (any file name works here too).

Courtesy of [payphones.telesfor.org](https://payphones.telesfor.org) and
included here with their attribution. The recordings are Elcotel's work;
this copy is for preservation and study of the hardware.
